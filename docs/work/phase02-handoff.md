# CouchZap — گزارش تحویل مرحلهٔ دوم

تاریخ: ۱۴ اکتبر ۲۰۲۶
مبنا: تغییرات مرحلهٔ اول در `ea1c29a`؛ نسخهٔ برنامه همچنان `2.0.2` / کد `8` است.

## نتیجه

تمام گزینه‌های برنامه‌ای تنظیمات اکنون داخل همان پنل و زیرصفحه‌های آن باز می‌شوند: اندازهٔ تصویر، ترک صدا/زیرنویس، تایمر خواب، منابع پلی‌لیست، راهنمای برنامه‌ها، حالت رابط، زبان، درباره، آپدیت و گزارش تشخیصی. انتخابگر فایل، ذخیرهٔ سند، اشتراک با برنامهٔ دیگر، مجوز نصب و نصب APK همچنان رابط استاندارد اندروید دارند.

## ناوبری و فوکوس

- `SettingsPanel` یک سربرگ ثابت و بدنهٔ اسکرولی با نشانگر اسکرول دارد. ریشهٔ تنظیمات و View والدها نگهداری می‌شوند.
- Back ریموت یا دکمهٔ بازگشت فقط یک زیرصفحه را می‌بندد؛ در ریشه، پنل بسته می‌شود. بستن پنل، کل پشتهٔ زیرصفحه‌ها را جمع می‌کند.
- گزینه‌ای که زیرصفحه را باز کرده است صریحاً ثبت می‌شود؛ این کار به فوکوس احتمالی قبلی Activity وابسته نیست و لمس را هم پوشش می‌دهد.
- فوکوس و اسکرول والد هنگام بازگشت بازیابی می‌شوند؛ درخواست دیررس بازیابی با نسل ناوبری محافظت می‌شود.
- یک زیرصفحه روی خودش تکرار نمی‌شود. گزینهٔ دارای فوکوس داخل محدودهٔ قابل‌دید قرار می‌گیرد.
- خطای پخش زیر پنل از مسیر فوکوس خارج می‌ماند؛ رگرسیون‌های مرحلهٔ اول حفظ شده‌اند.
- فایل‌یاب جایگزین CouchZap، در صورت نبود انتخابگر اندروید، داخل زیرصفحهٔ همین پنل قرار می‌گیرد. Back ابتدا پوشه‌ها را پیمایش می‌کند و در ریشه به والد تنظیمات برمی‌گردد.

## مالکیت کارهای پس‌زمینه

- آپدیتر، وضعیت بررسی/نسخهٔ موجود/درصد دریافت/آمادگی نصب/مجوز/خطا/انصراف را در عمر Activity نگه می‌دارد. خروج از زیرصفحه، اتصال نمایش به آن را قطع می‌کند؛ بازگشت وضعیت فعلی را نشان می‌دهد.
- یک کار فعال آپدیت اجازهٔ بررسی یا دانلود موازی نمی‌دهد. انصراف، کار را لغو می‌کند. مشاهدهٔ دوبارهٔ نتیجهٔ لغوشده یا خطا، بررسی خودکار تازه‌ای راه نمی‌اندازد.
- `ReleaseUpdater` و منطق اعتبارسنجی منبع، هش و امضای APK تغییری نکرده‌اند. فقط نمای دیالوگ‌ها عوض شده است.
- دریافت کاتالوگ عمومی متعلق به صفحه است و با خروج از آن لغو می‌شود؛ پاسخ دیررس صفحهٔ بسته‌شده را به‌روز نمی‌کند.
- دریافت پلی‌لیست و EPG متعلق به Activity است؛ وضعیت داخل صفحه نمایش داده می‌شود و اتصال View با خروج قطع می‌شود. دریافت هم‌زمان EPG دوباره آغاز نمی‌شود.
- گزارش تشخیصی پیش‌نمایش، کپی، ذخیره و اشتراک دارد. ارسال خودکار اضافه نشده و پالایش لاگ قبلی حفظ شده است.

## زبان و RTL

- در نصب تازه، انتخاب «فارسی / English» پیش از نمایش صفحهٔ ورود پلی‌لیست انجام می‌شود. هیچ منبعی خودکار وارد نمی‌شود.
- تغییر زبان در تنظیمات موجود است و در همان preferences قبلی ذخیره می‌شود. کاربران دارای پلی‌لیست قبلی مجبور به ورود دوباره نمی‌شوند و می‌توانند زبان را در تنظیمات انتخاب کنند.
- ۱۶۲ منبع رشتهٔ انگلیسی، معادل فارسی دارند. متن‌های خطا، وضعیت پخش، راهنمای ریموت، تنظیمات، ورود، آپدیت و عملیات لاگ ترجمه شده‌اند.
- تغییر زبان بدون recreate کردن Activity یا پاک‌کردن داده‌ها انجام می‌شود. پلی‌لیست و علاقه‌مندی‌ها حفظ می‌شوند؛ نمایش وضعیت پلیر از وضعیت واقعی دوباره خوانده می‌شود.
- فارسی RTL و انگلیسی LTR است. اتصال فیزیکی پنل کناری به سمت چپ حفظ شده است. جهت فلش Back و مسیر کلید افقی فهرست با زبان هماهنگ است.
- ورودی URL و پیش‌نمایش گزارش فنی LTR هستند؛ نسخه و برچسب منبع با BidiFormatter در متن فارسی قرار می‌گیرند. نام اصلی شبکه و متادیتای استریم ترجمه نمی‌شوند.
- انتخاب زبان پس از اجرای دوباره و تغییر configuration سیستم حفظ می‌شود.
- فونت فعلی، فونت سازگار سیستم اندروید است؛ Vazirmatn در این مرحله اضافه نشده و theme/font inflation عمومی تغییر نکرده است.

## اعتبارسنجی

- `testDebugUnitTest`: **۵۴ تست، صفر شکست، صفر skipped**.
- ۱۷ تست ریموت مرحلهٔ اول، تست session پلیر، parser، repository و بررسی امنیتی/حریم خصوصی موجود پاس شدند.
- ۱۱ تست جدید تنظیمات و زبان با Robolectric روی **API 24**: انتخاب اولیه، تغییر زندهٔ زبان، حفظ داده‌ها، بازگشت و اسکرول، زیرصفحه‌های همهٔ گزینه‌ها، ورودی LTR، خطای پخش هم‌زمان، پایین فهرست، وضعیت آپدیت/انصراف/خطا و کپی گزارش، restart و تغییر configuration.
- تست وضعیت دانلود از backend کنترل‌شده استفاده می‌کند؛ شمارش درخواست‌ها، حفظ درصد پس از خروج و بازگشت و نتیجهٔ آمادهٔ نصب آزموده شدند. این آزمون دانلود یا نصب واقعی APK نیست.
- `lintDebug`: **موفق، بدون خطا**؛ هشدارهای lint باقی‌اند و به‌عنوان صفر هشدار گزارش نمی‌شوند.
- `git diff --check`: بدون ایراد.
- تصاویر زیر با رندر واقعی Viewهای اندروید در Robolectric با native graphics روی **API 28** تولید شده‌اند؛ تصویر تولیدی هوش مصنوعی یا اسکرین‌شات از باکس کاربر نیستند.

## آزمون‌های باقی‌مانده و مرز مرحله

- ریموت و چرخهٔ Home/خاموش‌روشن روی باکس واقعی XDSR685 HDR، کیفیت پخش واقعی، نصب APK و رفتار انتخابگر/اشتراک اندروید روی دستگاه واقعی هنوز آزموده نشده‌اند. تست API 24 جای آزمون باکس واقعی را نمی‌گیرد.
- دریافت واقعی کاتالوگ/EPG، بررسی GitHub و نصب آپدیت جدید در این مرحله ادعای موفقیت ندارند؛ تست‌های رفتار آپدیت از پاسخ کنترل‌شده استفاده کردند.
- بررسی بصری API 28 انجام شد؛ رندر فونت روی سخت‌افزار API 24 همچنان نیازمند آزمون دستگاه است.
- ظاهر نهایی ورود، Free-TV و مرتب‌سازی الفبایی مربوط به مرحلهٔ ۳ هستند. انیمیشن‌ها، صدای CRT، پرداخت ظاهری و APK نهایی مربوط به مرحلهٔ ۴ هستند.
- هیچ APK نهایی، تغییر شمارهٔ نسخه، انتشار GitHub یا release انجام نشده است. مرحلهٔ ۳ خودکار آغاز نشده است.
