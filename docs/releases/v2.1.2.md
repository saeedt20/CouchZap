# CouchZap 2.1.2

Fixes for settings on Android phones and TV boxes, including the white overlay after pressing Back.

- Disable the platform's default focus highlight from API 26 onward. CouchZap's own focus styles remain active. Returning from a settings subpage no longer washes the entire panel white. The user confirmed this fix on a Xiaomi M2101K7AG running Android 16 / API 36.
- Move TV channel content slightly left by reducing its left safe inset from 5% to 3%, with a 24dp minimum.
- Restore the gap between Language and Check for updates.
- Keep Channel switch sound in a compact row with one remote focus target, readable labels and a checked accessibility state. Remove native button elevation/animation shadows.
- Add sanitized settings-Back focus diagnostics and regression coverage on newer Android versions.
