# CouchZap 3.1.0

**Stable release.** The native redesign graduates from beta with fixes for mobile Settings, Persian/Arabic presentation and remote navigation.

## Download and upgrade

Download [CouchZap-3.1.0.apk](https://github.com/saeedt20/CouchZap/releases/download/v3.1.0/CouchZap-3.1.0.apk) and its [SHA-256 checksum](https://github.com/saeedt20/CouchZap/releases/download/v3.1.0/CouchZap-3.1.0.apk.sha256).

- Android **7.0+ / API 24**, package `com.couchzap.iptv`, version **3.1.0**, version code **18**, target/compile API **35**.
- Uses the established release certificate and a higher version code than 2.2.1, 3.0-beta and 3.0-beta.2. Install over the existing official app to retain local data; do not uninstall first. Upgrade installation has not been checked on physical devices for this release.
- Users on **2.2.1** can use **Settings → Check for updates**. Users on **3.0-beta / 3.0-beta.2** should download this APK manually: those installed beta version names cannot be compared by the existing updater. The stable `3.1.0` version name restores compatibility with future stable updates.

## Changes since Beta 2

1. **Persian/Arabic Settings:** navigation row chevrons point left on phones and TVs; English, Spanish, Hindi and Thai retain right-pointing chevrons. The Channel switch sound toggle remains arrow-free.
2. **Next-channel preview:** Persian/Arabic previews appear at the physical top right. English retains its safe edge inset, and channel-change timing is unchanged.
3. **Localized clock:** the Info clock displays `۲۳:۲۴` in Persian and `٢٣:٢٤` in Arabic, following the selected app language and retaining the device time zone. Other app languages keep their previous formatting behavior.
4. **First-tap Settings:** mobile navigation and choice rows activate once on the first completed tap. Remote focus, language-selection return focus, cancellation and scrolling remain covered by regression checks.
5. **Simpler About:** short localized paragraphs, clear creator and MIT credits, runtime version, GitHub access and a dedication. Persian/Arabic credit **سعید طاهری**; other languages credit **Saeed Taheri**. The TV remote can scroll through the complete About page.

Includes the native TV/phone redesign and the [ten Beta 2 fixes](https://github.com/saeedt20/CouchZap/releases/tag/v3.0-beta.2), including keyboard dismissal after channel selection, cleaner Info controls, separated phone Settings sections, localized channel/group digits and native update-download progress.
