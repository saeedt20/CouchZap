# CouchZap 2.0.0

Take a seat. Start watching.

A redesigned native Android TV and phone player with a warm sage palette, a couch-and-lightning logo and easier remote navigation.

## What's new

- Larger, aligned welcome screen with local-file import and public channels from iptv-org.
- Playlist URLs, country/language/category selection, cached sources and manual refresh.
- Left-docked channel browser and settings, channel search, groups, logos and favourites.
- Circular remote focus: Up from the first visible channel reaches the last, and Down returns to the first. Playback changes only after selection.
- Compact Info plus expanded stream details, separate clock, play/pause state, favourites and previous watched channel.
- XMLTV/gzip guide import with matching `tvg-id`, now/next and programme progress.
- Available audio/subtitle selection and a sleep timer.
- DASH playback, HLS/DASH hints and content-type detection, clearer reconnect and retry states.
- Preserved favourites and channel identity across refreshed playlist order/URL changes.
- Correct QHD classification and dedicated Play/Pause keys; numeric selection supports large playlists.

## Install

Download **CouchZap-2.0.0.apk** below. Android 7.0/API 24 or newer is required. This is an optimized, signed release with application ID `com.couchzap.iptv`, version code `5` and version name `2.0.0`.

The attached `.sha256` file records the APK checksum. Future published updates must use the same release key. If an existing installation was signed with a different key, Android will require removing it first; uninstalling removes local app data.

## Validation

28 unit/Robolectric tests passed. Debug and optimized release builds completed; both lint variants had no errors. Screenshots in the README render real Android layouts with demo data and an illustrative background. Physical-device playback and remote compatibility still need testing on your device.

Streams, codecs, audio tracks and programme data depend on your source and hardware. Public channels are supplied by iptv-org and are imported on request.
