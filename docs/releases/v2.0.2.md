# CouchZap 2.0.2

Fixes public-channel imports on Android 7 and adds in-app updates and diagnostic sharing.

- Reproduced the public-directory failure with the device TLS stack: `SSLHandshakeException` / missing trust anchor. The official ISRG Root X1 public CA is now supplied for iptv-org and GitHub domains. System trust and hostname/chain verification remain enabled; no accept-all certificates or HTTP downgrade is used.
- **Settings → Check for updates:** fetch the latest stable GitHub release, download with progress/cancellation, verify SHA-256 and the CouchZap signing certificate, then offer Android installation with user confirmation.
- **Settings → Share diagnostic log:** preview, share or save a bounded app-only report. On boxes without sharing/document apps the report can be copied. URLs, playlist/channel names, tokens, exception messages and account data are excluded. Nothing is sent automatically.
- Import failures show a specific connection/timeout/security message and offer a diagnostic shortcut. An empty library no longer claims a previous playlist was preserved.

Validation includes unit/Robolectric tests, debug/release lint, optimized release assembly and native Android TV 7 / API 24 tests for public playlist parsing, country-directory downloads, a real official APK download with checksum/certificate verification, and the diagnostics dialog.

Install this APK over 2.0.1. The signing key is unchanged, version code is 8, and playlists/preferences are retained. Physical XDSR685 HDR hardware still needs the user’s confirmation.
