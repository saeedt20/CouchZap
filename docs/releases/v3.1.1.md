# CouchZap 3.1.1 release notes

**Stable release.** Version 3.1.1 (version code 19) refines the stable 3.1.0 base with four owner-reported improvements. Install over the official 3.1.0 app to keep your data; no uninstall needed. The corrected APK is signed with the established release certificate. See the [independent acceptance report](v3.1.1-verification.md).

## What changed

**Persian/Arabic Settings chevrons stay left after relaunch (highest priority).**
Settings navigation-row chevrons in Persian and Arabic now use fixed left-pointing assets bound directly from the saved app language, instead of relying on drawable auto-mirroring. The direction is applied on every row refresh — initial display, Settings open, live language switching, configuration changes and after exit/relaunch — so the arrows no longer revert to the right. English, Spanish, Hindi and Thai keep the right-pointing chevron. The channel-switch sound toggle remains chevron-free.

**Mobile Persian/Arabic About header points right.**
On phones, the About page header Back chevron in Persian and Arabic now points right. On TV it keeps pointing left, and all other languages keep the normal Back appearance. The About GitHub action row still points left in Persian/Arabic, and the page keeps its approved text, credits, MIT license, localized version, dedication and remote scrolling.

**TV choice pages focus the configured value.**
On TV/set-top-box, opening a choice list (language, interface mode, visual effects, picture size, sleep timer, audio/subtitle tracks) now puts the focus outline on the currently configured option instead of the first row. Focus is not selection: nothing changes until you confirm with OK. Mobile touch behavior is unchanged.

**Floating rotation button on phones.**
A new rotation control floats below the quick Settings gear during mobile playback. One tap switches to landscape; tap again to return to portrait. Your manual choice is kept for the session through rotations, language changes and layout updates. TV mode is unaffected and never shows the button.

## Verification

- **331 tests, zero failures/errors/skips**, independently verified locally and in [GitHub Actions](https://github.com/saeedt20/CouchZap/actions/runs/39025264063) on the exact corrected application commit.
- Debug and Release lint: **zero errors**; warnings remain. Both Debug and optimized Release builds pass.
- The accepted signed APK matches all **685 application payload entries** in both independent unsigned builds; v2/v3 signatures, established certificate, package/version and ZIP alignment pass verification.
- Native rendering and touch tests cover fixed glyph direction, selected TV focus, rotation persistence and separate mobile quick-action targets. The initial overlap/visibility defects were corrected before this APK was built and signed; see the historical [review record](v3.1.1-review.md).

## Honest limitations

- Physical-device checks were **not run**: no Android 7 XDSR 685 HDR box or Android 16 phone was available. The Persian/Arabic chevron-after-relaunch fix is validated by deterministic saved-language binding and lifecycle tests, not by hardware observation.
- The in-app updater on stable 3.1.0 recognizes the three-part `v3.1.1` tag and will offer the update. Users on the 3.0 prereleases still need one manual download.
