# CouchZap 3.0 Beta — Native redesign

**Beta, not stable.** Version 3 is available for early testing and is not yet as stable as [2.2.1](https://github.com/saeedt20/CouchZap/releases/tag/v2.2.1). Keep 2.2.1 for everyday watching and [report beta issues](https://github.com/saeedt20/CouchZap/issues). This release remains a GitHub prerelease.

## Changes

- Native TV Settings with **Playback / Playlist / App**, remembered rows and mirrored Persian/Arabic navigation.
- Grouped Settings on compact phones; phone Info keeps playback controls visible while technical details scroll.
- Shared adaptive metrics, bundled static fonts, native action/choice/focus components and reversible spring motion.
- **Visual effects:** Auto, Full depth, Safe and Off. Safe keeps video/subtitles untransformed; unsupported configurations select Safe conservatively.
- Virtualized public catalogs with one-step remote traversal, including long/filtered lists and held-key navigation.
- Optional welcome language selection, six interface languages and Persian/Arabic RTL.

## Install and returning to stable

Download **CouchZap-3.0-beta.apk** and its checksum from [this prerelease](https://github.com/saeedt20/CouchZap/releases/tag/v3.0-beta). Package `com.couchzap.iptv`, version **3.0-beta**, code **16**, Android **7.0+ / API 24**, target/compile API **35**. The committed source version now matches the published APK.

The signing certificate is unchanged, so the beta can install as an update over 2.2.1/code 15. Installing the older stable APK over the beta is a downgrade that ordinary Android installation rejects. Uninstalling to return to 2.2.1 can delete local playlists, favourites and settings. Stable 2.2.1 remains the default `releases/latest`; the beta is not promoted to stable.

## Validation and source correction

The complete independent source review on 16 October passed **156 unit/Robolectric cases**, with zero failures, errors or skips. The [machine-readable summary](../design/verification/final-tests-summary.json) records its exact source commit. Debug/release builds and lint previously passed on the design source; lint had zero errors with 207 Debug and 208 Release warnings, so this is not a warning-free claim.

The first beta tag pointed to the design commit whose Gradle version still said 2.2.1/code 15. This metadata/documentation correction aligns source and tag with the already-released 3.0-beta/code 16 APK. The signed APK and its checksum are retained. A fresh local Release build passed and all **680 app payload entries matched** the published beta, excluding only signing records and VCS build metadata. The CI metadata reader now accepts beta names, checks `codex/native-design`, uploads test/lint XML and compares a fresh unsigned build with the exact published beta using the existing payload verifier. See [branch CI](https://github.com/saeedt20/CouchZap/actions/workflows/android.yml?query=branch%3Acodex%2Fnative-design) and the [beta audit](../design/verification/beta-release-audit.json).

APK checksum, ZIP integrity, alignment and signatures for API 24–36 were independently checked. The certificate matches the actual downloaded 2.2.1 APK. No private signing key or password is packaged or added to the repository.

Physical-device checks remain **unverified**: XDSR 685 remote behavior, live blur/SurfaceView motion, HDR/decoder continuity and frame-time targets require device testing. Native screenshots use fixtures; source tests are not device or installed-APK instrumentation checks.
