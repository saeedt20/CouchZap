# CouchZap 2.0.1

Fixes an immediate launch crash on Android 7 before the welcome screen appears.

- Removes the global inline framework font-family override that triggered Android 7 resource string-pool errors during button inflation. The platform default font preserves the existing layout.
- Defers player creation until a channel is selected, including after returning from the background.
- Initializes UI controllers before asynchronous programme-guide work and handles an unavailable device-mode service safely.
- Adds an installed, optimized APK regression check on Android TV 7 / API 24: three cold launches, welcome-screen verification and remote Menu navigation to settings.

The signed APK uses the same release certificate as 2.0.0. Install it as an update; uninstalling first is unnecessary and would remove playlists and preferences. Version code 7 also replaces the earlier 2.0.1 test build.

Validation: [installed signed APK on Android TV 7](https://github.com/saeedt20/CouchZap/actions/runs/38491945542), unit/Robolectric tests, debug and release lint, optimized release assembly, and native API 24 emulator startup checks. Physical Xcruiser XDSR685 HDR hardware and its stream decoders still require device testing.
