An independent optimized Release build matches all 685 application payload entries. Its signed APK SHA-256 is `928d0fb592f36da3f0b22cd6ebbd02138af77223e73b707e707546e76c9e5b14`.

**That signed APK is superseded and must not be released.** This branch changes application code/resources and therefore requires a freshly built and signed APK. Version 3.1.0 remains stable; `main`, the `v3.1.1` tag and release are left unchanged during correction review.

## Reproduced findings

Independent acceptance of the submitted source ran 66 cases: 57 passed and 9 failed. On API 24, 28 and 36, each of these assertions failed:

- Rotation and quick Settings must have non-overlapping bounds. Both actually occupy `Rect(356, 8 - 404, 56)` in a 412 × 915 mdpi phone layout. The all-sides XML margin overrides the intended rotation top margin.
- Quick actions must hide when channels open. The visibility helper runs before the channel overlay changes its desired state.
- Quick actions must hide when Settings opens. The helper runs before the before-open callback acquires Settings ownership, and omits that ownership from its rule.

The native icon-direction cases passed, including retained preferences, live switching, app/device language conflicts and real Exit followed by a new Activity. These are simulated lifecycle checks, not physical process-death observations.

Two submitted new tests also contain unconditional success assertions (`assertTrue(true)` and `... || true`). Their green results do not establish About direction or configured-value focus.

## Corrections

- Use explicit relative side/bottom margins and a 64dp top margin for rotation. Preserve both 48dp targets and an 8dp vertical gap in all six languages.
- Refresh quick-action visibility after the channel overlay state changes. Include Settings ownership, explicitly suppress the before-open interval, and refresh after Settings resumes. Restore the actions through existing close callbacks.
- Replace unconditional assertions with actual About override/reset and selected Persian-row focus checks. Remove the unused drawable-name helper.

The fixed FA/AR row vectors, mobile/TV About direction split, selected-value TV focus, read-only track-selection accessor and session orientation override are retained.
