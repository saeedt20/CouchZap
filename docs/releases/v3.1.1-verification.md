## Requested behavior

- **Persistent FA/AR Settings chevrons:** physical left/right fixed vectors are selected from the saved app language on every refresh. Native pixel tests cover saved-language startup, live changes, device/app language conflicts, configuration changes and Exit followed by a new Activity retaining preferences. English/Spanish/Hindi/Thai keep right-pointing row chevrons; the sound toggle remains arrow-free.
- **Mobile FA/AR About header:** the header points right on phones and stays left on TV; the page override clears on leaving About. Native pixels verify the direction.
- **Configured-value TV focus:** language, mode, effects, picture size, sleep timer and audio/subtitle override pages focus the configured option. D-pad movement does not commit another preference or track; Back restores the origin. Supported synthetic track fixtures avoid network playback.
- **Phone rotation:** distinct 48dp Settings/rotation targets with an 8dp vertical gap, correct RTL/LTR alignment, real DOWN/UP dispatch to each control, Settings/channel ownership visibility, landscape/portrait changes, live-language retention and saved-instance restoration. TV never shows the rotation button.

The suite retains all 223 submitted cases, replaces the two unconditional About/focus assertions with behavioral checks and adds 108 matrix cases. UI/state coverage includes API 24, 28 and 36; native glyph pixel rendering uses API 28 and 36.

## Publication controls

Fresh public reconstruction data in `distribution/3.1.1/` binds the accepted signed bytes to the exact successful source CI artifact. Local reconstruction produces the accepted SHA-256 byte for byte. It contains only public APK/ZIP/signature data and cannot sign a different APK. Older version recipes remain unchanged.

The final tagged main commit must pass Android checks. The version-specific publisher verifies source ancestry, permits only documentation/publication changes after the corrected application commit, validates both source and final-main build-run identities, and compares the reconstructed signed APK against both independent artifacts. It checks the certificate, version, alignment and checksum again before uploading to a draft. Both uploaded asset digests must match before publication as **non-prerelease / Latest**. The publisher refuses to overwrite a public release.

After publication, download the actual public APK and checksum, verify the bytes and certificate, and check stable update discovery from 3.1.0. Source, signing and this publishing procedure do not claim a new device/emulator installation run.

## Physical checks and limits

**Not run:** physical XDSR 685 HDR Android 7, Android 16 phone, actual upgrade installation, hardware decoder/HDR playback and a new Android TV emulator flow. Simulated Activity lifecycle is not actual OS process death; dispatched touch tests do not prove hardware rotation or uninterrupted device playback. The owner-reported prior chevron reversal was not reproduced as a hardware root cause; the correction removes auto-mirroring dependence and binds deterministic saved-language assets.

Install the official APK over official 3.1.0 to retain local data; do not uninstall first. Stable 3.1.0 can recognize the three-part `v3.1.1` update. Users on the older 3.0 prereleases need one manual download because their installed beta version names cannot be compared by the updater.
