## Publication checks

The publication workflow requires a successful complete Android-checks run on the final main commit, verifies that only documentation/publication files differ from the corrected application source, and compares the final main unsigned build with the accepted signed APK. It checks certificate, version, alignment, checksums and draft assets before publishing `v3.1.0` as stable/Latest. Existing public releases and assets are left intact.

The three-part version name is intentional: the updater shipped in stable 2.2.1 accepts `x.y.z`. Beta-installed version names require one manual upgrade to 3.1.0. The stable release must expose exactly `CouchZap-3.1.0.apk` and `CouchZap-3.1.0.apk.sha256` at the expected GitHub download URLs.
