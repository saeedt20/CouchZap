# CouchZap 2.2.0

Six interface languages and a simpler first launch for Android TV and phones.

## Changes since 2.1.4

- Open the welcome screen directly. The separate required language page is removed; language selection remains available on welcome and in Settings.
- Add complete Spanish, Hindi, Thai and Arabic translations for interface messages, settings, updates, diagnostics and known channel categories.
- Use the same language order everywhere: **English, Español, हिन्दी, ไทย, فارسی, العربية**.
- Arabic follows Persian RTL text, right-docked channel/settings panels, bidirectional labels and remote navigation. English, Spanish, Hindi and Thai use left-docked panels and LTR layout.
- Apply language changes immediately and preserve the selected language after restarting, along with playlists, favourites and interface preferences.
- Refresh README instructions, the language table and screenshots for all six languages.
- Name CI build artifacts from the app version and require a matching reviewed release recipe before signed publication.

## فارسی

- ورود مستقیم به صفحهٔ خوش‌آمدگویی و حذف صفحهٔ اجباری انتخاب زبان.

- حفظ زبان انتخابی پس از بستن و بازکردن برنامه و نگهداری پلی‌لیست‌ها و علاقه‌مندی‌ها.

## Build and compatibility

Package: `com.couchzap.iptv`. Version code: **14**. Minimum Android: **7.0 / API 24**. Target API: **35**.

The signed release asset will be named **CouchZap-2.2.0.apk**, accompanied by **CouchZap-2.2.0.apk.sha256**. Signing must use the existing CouchZap release key so the APK can update 2.1.4 without uninstalling or losing local data. An unsigned CI artifact is a build input for signing, not an installable update.

## Validation

- The multilingual implementation passed **119 unit/Robolectric cases** with no failures, errors or skips in [GitHub Actions](https://github.com/saeedt20/CouchZap/actions/runs/38727661676), including API 24/28/36 coverage.
- Debug and Release lint passed with zero errors; existing warnings remain. Debug and optimized Release assembly passed.
- All **208** string/category resources and format placeholders match the default resource set in each new locale.
- Native screenshots cover the six-language welcome on TV and phone and the English/Arabic panels. Images use fixture data, not live streams.
- Signed publication requires the existing private release key, payload/signature/checksum verification and an Android TV 7 flow check of the signed APK. See the [publishing process](publishing.md).

Physical remote behavior, hardware decoding and live stream availability still depend on the device and sources.
