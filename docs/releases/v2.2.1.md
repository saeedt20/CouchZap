# CouchZap 2.2.1

Fix remote navigation in long public playlist catalogs, reported on the XDSR 685 HDR running Android 7.

## Changes

- Fix Up/Down skipping many countries in **Playlist sources → Start with public channels → iptv-org → Choose a country**.
- Read focus from the active panel and give each catalog row explicit previous/next targets. A short press moves one row; a held key advances in order.
- Rebuild navigation targets after searching, keep empty results focused on search, and stop at the last result.
- Apply the same behavior to public country, language and category pickers in English, Persian, Arabic and the other supported interface languages.
- Preserve phone touch selection and text editing, playlists, favourites and existing language settings.

## فارسی

رفع پرش چندین کشور با دکمه‌های بالا و پایین ریموت در فهرست منابع عمومی. حرکت ردیف‌به‌ردیف، انتخاب گزینه‌های میانی و جست‌وجو در اندروید ۷ و همهٔ زبان‌های رابط بررسی می‌شود.

## Compatibility and validation

Package `com.couchzap.iptv`, version code **15**, Android **7.0+ / API 24**, target API **35**. The signed APK uses the existing release key and can update 2.2.0 without uninstalling.

Regression coverage traverses a 240-country list in both directions, selects middle rows, filters/clears results and tests held-key navigation in LTR/RTL on API 24 and 36. The signed publication workflow also checks adjacent country-row navigation on Android TV 7 before publishing.
