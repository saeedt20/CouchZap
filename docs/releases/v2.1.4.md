# CouchZap 2.1.4

Continuous channel search, clearer favourite state and a more complete Persian interface on phones and TV boxes.

## Changes since 2.1.2

- Search keeps accepting words, spaces and composing text while results update. Entering search cancels pending channel-row navigation; implicit keyboard events no longer submit the query. Explicit Search/Done/Go or Enter opens matching results, and an empty result keeps the editor available.
- Persian channel and settings panels dock on the right; English panels dock on the left. TV safe padding follows the panel edge.
- Known IPTV groups are translated in both the Groups picker and channel rows. Custom group names and the original playlist identities remain intact. Persian interface choices display **تلویزیون**, and picture ratios display **۱۶:۹** and **۴:۳**.
- Language matches the other settings buttons. Interface mode shows the selected value without repeating the Interface prefix.
- Settings hide their scrollbars on phones and TV boxes while remaining scrollable. The channel list retains its scrollbar on both.
- The Info favourite button shows an outlined star when absent and a filled star when added; accessibility state and action labels update with it.
- Retain the Android 16 white-halo fix, Android 7 startup/TLS fixes and existing playlist/favourite persistence.
