# CouchZap 2.1.0

A calmer TV interface with reliable remote navigation, Persian/English settings and optional public sources.

- Channel browsing retains remote focus across long lists, offscreen wrapping and asynchronous playback errors. Playback status is separate from the highlighted row; holding OK toggles favourites once.
- Settings share one panel with retained parent focus and scroll on Back. Persian uses RTL content and English LTR; language can be changed without removing playlists or preferences.
- Welcome offers your playlist or optional public channels. Choose iptv-org country/language/category lists or Free-TV country/themed lists. Name sorting preserves source channel numbers and stable favourites/current-channel identity. Failed or cancelled imports preserve previous data.
- Channels and settings share their width and TV safe margins. Info gives the channel name/logo priority, with number and clock underneath. Compact rows keep 48dp or larger touch targets and clear remote focus.
- The short first welcome intro accepts input immediately; the first key or touch completes it and still works. System animation settings are respected; Android 7 overlays keep immediate opening.
- **Settings → Playback → Channel switch sound** enables a quiet, original 160ms CRT click. Default is off. It previews on enable and plays only for committed channel changes, with media mute/volume respected; browsing, retries and reconnects stay silent.

## Install

Download **CouchZap-2.1.0.apk**. The APK uses the existing CouchZap release certificate, package `com.couchzap.iptv`, version code **9**, minimum Android **7.0 / API 24** and target API **35**. Install over the previous signed release to retain local playlists, favourites and preferences. The accompanying `.sha256` file verifies the exact published APK. Existing releases are left unchanged.
